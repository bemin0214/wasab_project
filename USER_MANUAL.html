1. 사용 전 안전 확인

로봇을 움직이기 전에 반드시 확인하세요. 로봇팔과 이동로봇의 동작 반경에 사람, 의자, 가방 등 장애물이 없어야 합니다.
  • 왼팔·오른팔 주변의 작업 공간이 비어 있습니다.
  • 그리퍼에 끼이거나 떨어질 위험이 있는 물체가 없습니다.
  • Pinky 이동 경로와 순찰 구역에 장애물이 없습니다.
  • 카메라, 전원, USB 시리얼 케이블이 연결되어 있습니다.
  • 운영자는 화면 상단의 빨간색 정지 버튼 위치를 알고 있습니다.

2. 시스템 시작

일반 운영은 WaSaB 통합 실행기를 사용합니다.

1

통합 실행기 열기

Ubuntu 바탕화면의 WaSaB 통합 실행기를 더블클릭합니다.

2

실행 항목 선택

필요한 Server & GUI, Left/Right Arm, Pinky 항목을 체크합니다. 전체 구동 시 ALL SELECT를 사용합니다.

3

주소 확인

AI Server IP, 로봇팔 IP와 ROS Domain, 각 Pinky의 IP와 Domain이 실제 장치 설정과 일치하는지 확인합니다.

4

선택 항목 시작

시작 버튼을 누르고 Status가 실행 중으로 바뀔 때까지 기다립니다. 통합 GUI는 준비 후 자동으로 열립니다.

GUI가 자동으로 열리지 않으면 같은 PC의 브라우저에서 http://127.0.0.1:8100에 접속합니다.

3. 로그인

아이디 로그인

발급받은 아이디와 비밀번호를 입력한 뒤 로그인 버튼을 누릅니다.

Face 로그인

Face 로그인 버튼을 누르고 카메라 정면을 바라봅니다. 등록 얼굴과 일치하면 자동 로그인됩니다.

관리자 계정

계정관리와 로봇암 현황 등 관리자 기능이 표시됩니다. 계정 정보는 관리자에게 문의합니다.

얼굴을 인식하지 못하면 조명을 확인하고 카메라 중앙에서 다시 시도합니다. 계속 실패하면 아이디 로그인을 사용합니다.

4. 홈 화면 사용

  • 로봇별 온라인 상태, 임무, 배터리

6. 순찰 당직

1

가용 로봇 선택

순찰 홈에서 온라인·대기 상태인 Pinky를 선택합니다.

2

순찰 시작

순찰 시작을 누르면 지정 경로 자율 순회가 시작됩니다. 위치맵과 현재 구역을 확인합니다.

3

감지 상황 대응

화재 등 이벤트가 표시되면 감지 상황 → 출동 진행 → 현장 확인·조치 순서로 확인합니다.

분리수거

순찰 당직 화면의 초록색 분리수거 버튼 또는 상위 메뉴의 분리수거 탭을 사용합니다. Left Arm이 water와 trash를 구분해 지정 수거함에 배치합니다.

7. 로봇암 기능

로봇암 현황

관리자 메뉴의 관리 → 로봇암 현황에서 Left Arm, Right Arm, Dual Arm을 선택할 수 있습니다. 서버 연결, 카메라, 기능 상태, 동작 버튼과 실시간 로그를 확인합니다.

얼굴인식, 화재감지, 추종은 같은 팔에서 동시에 실행되지 않습니다. 하나를 켜면 다른 비전 기능은 자동으로 꺼집니다.

8. 로봇 현황·알림·이벤트

로봇 현황

Pinky별 연결, 모드, 배터리, 위치를 확인하고 수업 보조 또는 순찰 당직 화면으로 이동합니다.

알림

현재 확인이 필요한 화재·경고·긴급정지 알림을 최신순으로 확인합니다.

종합 이벤트

로그인, 명령, 모드 변경, 온라인 상태, 로봇팔 실행 결과를 검색하고 시간순으로 확인합니다.

9. 비상정지

충돌 위험, 예상하지 못한 이동, 사람 접근 시 즉시 화면 상단의 빨간색 정지 버튼을 누릅니다.

전체 정지

전 로봇 즉시 정지는 이동로봇과 로봇팔에 정지 명령을 전달합니다. 상황이 안전해진 뒤에만 정지 해제를 누릅니다.

개별 정지

목록에서 Pinky, Left Arm, Right Arm 또는 Dual Arm을 선택한 뒤 해당 행의 정지 버튼을 누릅니다.

Dual Arm 정지는 선물주기처럼 양팔 시나리오로 실행된 동작을 멈출 때 사용합니다. 정지 후에는 장치 주변을 확인하고 필요하면 Home 동작으로 복귀시킵니다.

10. 정상 종료

1

임무 종료

순찰과 수업 보조를 종료하고 Pinky를 홈으로 복귀시킵니다.

2

로봇팔 안전 자세

진행 중인 동작이 없는지 확인하고 필요하면 로봇암 현황에서 Home을 실행합니다.

3

전체 종료

통합 실행기의 전체 종료 버튼을 사용합니다. 강제로 창만 닫기 전에 프로세스 상태를 확인합니다.

11. 문제 해결

증상확인 및 조치
GUI가 열리지 않음통합 실행기에서 Web GUI 상태를 확인하고 브라우저에서 http://127.0.0.1:8100을 직접 엽니다.
로봇팔 기능이 실행되지 않음AI Server와 해당 Arm이 실행 중인지 확인한 뒤 로봇암 현황의 서버 상태와 로그를 확인합니다.
카메라 영상이 없음카메라 연결과 다른 프로그램의 점유 여부를 확인하고 해당 팔 클라이언트를 재시작합니다.
얼굴을 인식하지 못함조명과 얼굴 방향을 조정합니다. 등록 사용자 사진 및 얼굴 데이터가 준비되어 있는지 관리자에게 문의합니다.
Pinky가 오프라인전원, Wi-Fi, IP와 ROS Domain을 확인하고 통합 실행기에서 해당 Pinky 항목을 다시 시작합니다.
버튼이 비활성화됨교실이동·홈복귀·모션 지시는 얼굴 인증이 필요합니다. 로봇 선택 또는 현재 임무 상태도 확인합니다.

12. 빠른 운영 점검표

  • 작업 반경과 이동 경로가 안전하다.
  • AI Server, Web GUI, 사용할 Arm/Pinky 상태가 실행 중이다.
  • IP와 ROS Domain이 실제 장치와 일치한다.
  • 홈 화면에서 온라인 상태와 배터리를 확인했다.
  • 기능 실행 전 대상 장치와 확인창 내용을 확인했다.
  • 비상정지 버튼의 위치와 개별 장치 선택 방법을 알고 있다.
  • 종료 전에 임무 종료와 홈 복귀를 완료했다.
